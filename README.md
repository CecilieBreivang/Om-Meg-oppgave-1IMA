# Om meg-nettside

I denne oppgaven skal du lage en «Om meg»-nettside som presenterer deg selv. Du bygger siden med HTML (og litt CSS hvis du velger det mest krevende nivået), og du leverer den som et repository på GitHub.

## Velg nivå

Du velger selv hvilket nivå du vil jobbe på. Hvert nivå har sin egen oppgavetekst med oppgaver, sjekkliste og innlevering.

| Nivå | Hva du jobber med | Oppgave |
| --- | --- | --- |
| Nybegynner | Grunnleggende HTML og riktig kodestruktur. Ingen CSS. | [Gå til oppgaven](README-nybegynner.md) |
| Viderekommen | Semantisk HTML, tabeller og flere sider som henger sammen. Ingen CSS. | [Gå til oppgaven](README-viderekommen.md) |
| Avansert | Alt fra Viderekommen, pluss litt CSS i en egen fil. | [Gå til oppgaven](README-avansert.md) |

## Dette trenger du

- En GitHub-konto på [github.com](https://github.com/)
- GitHub Desktop
- Visual Studio Code

## Slik lager du et repository

Før du skriver kode skal du opprette et eget repository på github.com og åpne det i GitHub Desktop. Derfra åpner du prosjektet i VS Code. Repositoryet er der du lagrer alt du lager i oppgaven, og det er det du leverer inn til slutt.

1. Logg inn på github.com, og trykk **New** for å opprette et nytt repository. Gi det et navn, for eksempel `om-meg-nettside`, og trykk **Create repository**.
2. Trykk den grønne **Code**-knappen på repository-siden og velg **Open with GitHub Desktop**. Alternativt kan du velge **File → Clone repository** i GitHub Desktop og finne repositoryet i listen.
3. Velg en plassering på PC-en under **Local path**, og trykk **Clone**. Husk hvor mappen ligger. Dette blir prosjektmappen din.
4. Trykk **Open in Visual Studio Code** i GitHub Desktop for å åpne prosjektmappen i VS Code. Alle filene til nettsiden skal lages her.

## Slik lagrer du arbeidet ditt

Når du har fått til en del av oppgaven:

1. Gå til GitHub Desktop og skriv en kort beskrivelse av hva du har gjort i **Summary**.
2. Trykk **Commit to main**.
3. Trykk **Push origin** slik at endringene dine ligger på GitHub.

Gjør dette flere ganger underveis, ikke bare helt til slutt.

## Innlevering

Oppgaven leveres som lenken til repositoryet ditt på GitHub:

1. Kontroller i GitHub Desktop at alle endringer er committet, og trykk **Push origin** slik at siste versjon ligger på GitHub.
2. Åpne repositoryet på GitHub.com og sjekk at alle filene er der.
3. Lever inn lenken til repositoryet innen fristen på Teams. Kontroller at læreren har tilgang til repositoryet (public).
